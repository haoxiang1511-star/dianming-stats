远程设置怎么改（不用重新发版）›
  1. 浏览器打开 uniCloud 控制台，登录后进入服务空间 test1。
  2. 左侧点「云数据库」，打开表 dm_config，找到 _id 为 main 的那条，点编辑。
  3. 按下表改字段，保存即可。手机在下一次汇报时拿到新设置。
字段作用例子
report_interval_days每台手机隔几天汇报一次（1～90）。用户多了可以改大，省数据库额度。1 每天一次；7 一周一次
enabled统计总开关。改成 false 后服务器不再存数据，手机也停止汇报（每 7 天只轻问一次设置）。改回 true 恢复。true / false
admin_key看这个页面用的密钥，至少 16 位。改了以后，这里要用新密钥重新登录。一串随机字符，别外传

说明：「活跃」按每台手机最近一次汇报的时间算。汇报间隔改成 7 天后，1 天活跃的数字会偏低，属于正常现象。每台手机当天的数据会攒到第二天第一次打开时一起发，所以今天的使用要明天才看得到。
